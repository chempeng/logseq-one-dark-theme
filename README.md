# One Dark Pro for Logseq

An unofficial dark theme for Logseq inspired by [Binaryify's One Dark Pro](https://github.com/Binaryify/OneDark-Pro). It styles the interface, notes, embeds, and code editor.

## Install

After the theme is listed in the Logseq Marketplace, open **Plugins → Marketplace → Themes**, search for **One Dark Pro**, and install it. Then select **One Dark Pro** from Logseq's theme menu.

For a manual install, enable Developer mode in Logseq, choose **Plugins → Load unpacked plugin**, and select this folder.

## Agenda

The theme includes optional styling for [Logseq Agenda](https://github.com/haydenull/logseq-plugin-agenda). The compact `🍅×N` display needs the separate [Agenda helper](integrations/agenda/compact-pomodoro.js); the theme works without it.
